# Chiu Know?

Aplicativo Android multilíngue de aprendizagem de idiomas da família Chiu.

## Documentação autoritativa
- `PROJECT_STATE.md` — continuidade, estado real e regras de segurança/Supabase.
- `PRODUCT_SPEC.md` — visão e requisitos funcionais.
- `VISUAL_BIBLE.md` — identidade visual, elenco e regras absolutas dos mascotes.
- `RESEARCH.md` — pesquisa técnica, referências e cautelas de licenciamento.

## Regra de continuidade
Antes de qualquer alteração, ler `PROJECT_STATE.md` e os documentos relevantes. Conferir o estado real do GitHub e, antes de qualquer escrita no backend, validar por leitura que o plugin Supabase está conectado ao projeto Chiu Know? correto. Nunca usar o backend do Chiu Player neste repositório.

## Estado atual
Fase de fundação: especificação e isolamento do backend estabelecidos. A estrutura inicial do aplicativo Android ainda será criada de forma incremental e reversível.
